# Ticketly Admin P0 UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Xây dựng 14 bề mặt Admin P0 có route độc lập, mock workspace, workflow kiểm duyệt/vận hành và audit log để kiểm chứng domain trước khi thiết kế database.

**Architecture:** Thêm `AdminApplication` song song với Attendee và Organizer. `App.tsx` sở hữu một `useAdminWorkspace()` cho cả phiên; page gọi controller hẹp, controller dispatch vào pure reducer; dashboard và queue luôn được derive từ canonical records. Không có backend, persistence hoặc dependency runtime mới.

**Tech Stack:** React 19.2, TypeScript 6, Vite 8, Tailwind CSS 4, Node test runner, History API hiện có.

**Spec:** `docs/2026-09-05-admin-p0-ui-design.md`

## Global Constraints

- User-facing copy dùng tiếng Việt.
- Dữ liệu chỉ là fixture + React state và reset khi reload.
- Không dùng `fetch`, WebSocket, browser storage, cookie hoặc API thật.
- Không thêm runtime dependency.
- Một role Admin P0; chưa có RBAC.
- Amount của order, payment, refund và payout luôn readonly.
- Approve event không bắt buộc reason; request changes/reject/restrict/hide/hold bắt buộc reason không rỗng.
- Mỗi sensitive action thành công sinh đúng một audit entry; action bị từ chối không sinh audit.
- Không hard delete; không trực tiếp sửa order/payment/ticket credential.
- File TypeScript/TSX mới dùng kebab-case và nên dưới 200 LOC.
- Target directory không có `.git`; thay commit steps bằng validation checkpoint, không khởi tạo repository.

export type AdminRoute =

export function getAdminEventId(pathname: string): string | null

- [ ] **Step 5: Implement one pure reducer with atomic helper**

Use a single success helper:

```ts
function completed(
  state: AdminWorkspace,
  action: AdminWorkspaceAction,
  nextState: Omit<AdminWorkspace, 'auditEntries'>,
  audit: AdminAuditEntry,
  result: AdminOperationResult,
): AdminWorkspaceTransition {
  return { state: { ...nextState, auditEntries: [audit, ...state.auditEntries] }, result }
}
```

Do not let pages construct audit entries. Action carries injected `occurredAt` and `auditId`; reducer derives action/target/reason labels.
